# Evidencias del proyecto

Esta carpeta contiene las evidencias del funcionamiento del pipeline de datos contenerizado.

## Evidencias que se deben recopilar

1. Construcción e inicio correcto de los contenedores Docker.
2. Procesamiento de los 5,000,000 de registros con Hadoop Streaming.
3. Procesamiento secuencial de los datos.
4. Comparación de los 240 resultados y validación de que no existen diferencias.
5. Conexión correcta de la API con PostgreSQL.
6. Consulta de los 240 resultados mediante la API.
7. Conexión SSH entre los contenedores sin contraseña.
8. Repositorio de GitHub con los commits del proyecto.

Las capturas deben mostrar los comandos ejecutados y sus resultados.
